# @bingwu-my-monorepo/mobile

移动端 H5 应用，基于 Vue 3 + Vant 4 + Vite 构建。

## 技术栈

- Vue 3 + TypeScript
- Vant 4 组件库
- Tailwind CSS 3 原子类框架
- Pinia 状态管理
- Vue Router 4（Hash 模式）
- Axios 请求封装
- vmin 视口适配（PostCSS px-to-viewport）

## 开发

```bash
# 从 monorepo 根目录启动
pnpm dev:mobile

# 或在当前目录
pnpm dev
```

默认开发端口：`3002`

## 构建

```bash
pnpm build:mobile
```
